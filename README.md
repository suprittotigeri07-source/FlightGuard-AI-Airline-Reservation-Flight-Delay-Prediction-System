# FlightGuard AI: Airline Reservation & Flight Delay Prediction System

FlightGuard AI is an intelligent airline reservation system integrated with machine learning models to predict flight delays and provide real-time updates and seamless booking experiences.

## Features
- **Airline Reservation**: Search, book, and manage flight reservations.
- **AI Flight Delay Prediction**: Real-time delay risk assessments based on historical weather, schedule, and route data.
- **Smart Dashboard**: Visual analytics for flight status, predictions, and passenger itineraries.
